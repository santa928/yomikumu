# 港の写真展を直す

ZIPを展開し、そのフォルダーで作業します。index.html をテキストエディターで、同じファイルをブラウザで開きます。ファイルで直接開いたときは、画像が見つからないと「ファイルが見つかりません」と出ます。HTTPの404を確認するには教材の「修正前のページを開く」も使えます。

1. ブラウザの開発者ツールのNetworkを開き、再読み込みします。画像の要求先と展開先の assets フォルダーの内容を比べ、index.html の src を修正してください。
2. 開催中の見出しを右クリックし、「検証」のStylesでどの色が採用されたかを確かめます。styles/exhibit.css を編集し、この見出しだけを green にします。保存して再読み込みします。
3. 連絡先に a@example.com を入れて「送る内容を見る」を押します。index.html の入力欄に項目名 email を付け、空欄と hello は送れず、a@example.com なら email = a@example.com と表示されるようにします。
4. 写真と二つの見出しが表示され、ラベルを押すと入力欄に移ることも確認します。他の人が同じ不具合と修正を確認できるよう、修正したファイル・試した入力・結果を3行で記録してください。

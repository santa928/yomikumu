# よみくむ

スライドでコードを読み、自分で書いて確かめる、日本語のプログラミング学習サイトです。最初のコースでは、HTMLとCSSで好きな作品を紹介するページを作ります。

このリポジトリをダウンロードして展開し、[コース目次](index.html)をブラウザで開いてください。HTMLとCSSの7単元に、それぞれスライド、四択、記述練習があります。卒業制作では二つの作品を紹介するページを作り、単体のHTMLとして書き出せます。利用料・アカウント登録・外部APIは不要です。

同じブラウザでは前回の位置と練習の下書きを保存します。別の端末で続けるときは、コース目次の「進捗と下書きの引き継ぎ」からファイルを渡してください。進捗ファイルには自分が入力したコードも入ります。公開するリポジトリに追加する必要はありません。

スマホでファイルからJavaScriptを実行できない環境では、PC上で次のコマンドを実行し、同じWi-FiからPCのアドレスとポート8080を開けます。教材は読み取り専用で配信します。この間、同じネットワークから教材にアクセスできます。終了は Ctrl+C です。

```sh
docker compose up web
```

[コースの到達点と教材の基準](docs/course.md)

開発時の操作確認は `docker compose run --build --rm test` で実行できます。テスト用イメージの初回取得後、ブラウザ検証は外部通信なしで動きます。

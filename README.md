# よみくむ

スライドでコードを読み、自分で書いて確かめる、日本語のプログラミング学習サイトです。Web制作はHTMLで作品名を変えるところから、Pythonは作品展の受付で名前を表示するところから始められます。

[よみくむで学習を始める](https://santa928.github.io/yomikumu/)

[JavaScript入門](https://santa928.github.io/yomikumu/#javascript)では、展示の看板を書き換え、クイズの開始点と正解後の得点を表示します。ブラウザで記述・実行・停止ができ、コンソールには値とその種類が表示されます。

スマホでもPCでも、上のリンクからすぐに学べます。作品名を一行書き換えて表示を確かめるところから始めます。各単元にはスライド、四択、コード練習があります。スマホではタップでコードを組み、PCではキーボードで書きます。どちらの端末でも練習方法を選べます。卒業制作では二つの作品を紹介するページを作り、単体のHTMLとして書き出せます。利用料・アカウント登録は不要です。

同じブラウザでは前回の位置と練習の下書きを保存します。別の端末で続けるときは、コース目次の「進捗と下書きの引き継ぎ」からファイルを渡してください。進捗ファイルには自分が入力したコードも入ります。公開するリポジトリに追加する必要はありません。

## 手元で開く

オフラインで使うときは、このリポジトリをダウンロードして展開し、`index.html` をブラウザで開いてください。手元の教材を同じWi-Fiのスマホで試すときは、PC上で次のコマンドを実行し、スマホからPCのアドレスとポート8080を開きます。終了は Ctrl+C です。

```sh
docker compose up web
```

[コースの到達点と教材の基準](docs/course.md)

開発時の操作確認は `docker compose run --build --rm test` で実行できます。テスト用イメージの初回取得後、ブラウザ検証は外部通信なしで動きます。

ブラウザとPCでの実行方法
この画面は端末内の Skulpt で教材の Python 3 コードを実行します。名前・コードは端末内に保存します。回線やアカウントは不要です。追加パッケージの導入やPC上のファイルの操作は、PCに用意した CPython で試せます。
PCではコードを main.py に保存し、同じフォルダーをターミナルで開いて python3 main.py（Windowsでは py main.py）を実行します。入力は一行ずつ Enter で渡し、停止は Ctrl+C です。別ファイルがある例は同じフォルダーに保存します。
